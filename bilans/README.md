# bilans/ : ce que tes posts ont donné

Rempli par la skill `bilan-performance` (dis « mon bilan », ou en routine le 1er lundi du mois) :

- `performances.csv` : le dernier relevé de tes posts suivis par Zernio (impressions, portée, réactions, commentaires, partages, enregistrements), via `scripts/zernio.py resultats` ;
- `AAAA-MM-JJ-performances.csv` : les relevés archivés, pour suivre l'évolution ;
- `AAAA-MM-bilan.md` : le bilan du mois et ses 3 décisions (garder, arrêter, tester).

Versionné, comme `veille/` : garde ton agent dans un dépôt **privé**, ces chiffres sont les tiens.
